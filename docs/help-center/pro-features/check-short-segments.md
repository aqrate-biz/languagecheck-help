# Check Short Segments

<div class="plan-badges"><span class="plan-badge plan-pro">Pro</span><span class="plan-badge plan-team">Team</span></div>

Use short-segment checks to highlight source segments that may not provide enough context for a reliable quality assessment.

## Steps

1. Open **New check**.
2. In advanced checks, enable **Short segments**.
3. Set the maximum number of source words. The default is 3; the minimum is 1.

## Results

A segment is flagged when its source contains the selected number of words or fewer. The Excel report includes a **Short Segment Issue** column, and annotated XLIFF comments include the source word count and selected limit.

Short segments may lack sufficient context for a reliable quality assessment.
