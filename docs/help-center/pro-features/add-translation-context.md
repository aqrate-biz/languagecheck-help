# Add Translation Context

<div class="plan-badges"><span class="plan-badge plan-pro">Pro</span><span class="plan-badge plan-team">Team</span></div>

Add translation context to help LanguageCheck understand your document's subject area and assess ambiguous or domain-specific translations more accurately.

## Steps

1. Open **New check**.
2. Expand **Add Translation context**.
3. Find the **Translation context** field.
4. Enter a brief description of your document or subject area, up to 250 characters.
5. Continue with your check as usual.

## Notes and Limitations

Translation context is optional. Keep it short and focused on the document's subject matter. For example: *"Technical manual for industrial electric motors."*

Translation context helps the AI interpret translations more accurately. It does not replace a termbase and should not be used for terminology lists, style guidelines, or additional translation instructions.
