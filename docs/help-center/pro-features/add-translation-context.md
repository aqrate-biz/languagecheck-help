# Add Translation Context

<div class="plan-badges"><span class="plan-badge plan-pro">Pro</span><span class="plan-badge plan-team">Team</span></div>

Translation context helps LanguageCheck understand your document's subject matter and evaluate ambiguous, short, or highly technical segments more accurately. You can enter context yourself or let LanguageCheck generate it by analyzing the source text in your uploaded files.

## Using Translation Context for the First Time

The first time you open **Add Translation Context**, enter a brief description of your document, its subject matter, or relevant technical information. The manual context can contain up to 250 characters.

Before starting the quality check, the summary page shows two options:

- **Your translation context**: the description you entered.
- **AI-generated translation context**: a context created by LanguageCheck based on your source files.

Choose the context you want to use before selecting **Let's go**.

## Using Translation Context on Subsequent Checks

From your second use onwards, **Add Translation Context** offers two options.

### Generate a Context Automatically

Choose **Generate a translation context automatically from my files**. LanguageCheck analyzes your source files and generates a context tailored to them. The summary page displays this generated context; it is read-only and cannot be edited.

### Enter a Context Manually

Choose **Enter a translation context manually** and describe your document or its subject matter in up to 250 characters. LanguageCheck also generates an alternative context from your source files.

On the summary page, choose whether to use your manual context or the AI-generated alternative before selecting **Let's go**.

## Which Option Should You Choose?

For most documents, the AI-generated context is a convenient choice: LanguageCheck analyzes the source content to identify the subject matter, technical domain, and relevant terminology.

Your own context may be more useful when you know something specific about the document that may not be apparent from its contents.

## Notes and Limitations

Translation context provides supplementary background information to help interpret translations. It does not replace a termbase or a style guide.
