# Send LanguageCheck Results to Phrase

<div class="plan-badges"><span class="plan-badge plan-pro">Pro</span><span class="plan-badge plan-team">Team</span></div>

Use the Phrase workflow when the check includes MXLIFF files.

## Connect LanguageCheck to Phrase

Have a Phrase TMS access token ready. You can connect before opening a check or the first time you send results to Phrase.

To connect from Settings:

1. Open the user menu and select **Settings**.
2. Expand **Phrase**.
3. Enter your token in **Insert Phrase TMS access token** and select **Submit**.
4. Confirm that the status changes to **Connected**.

You can also enter the token when you select **Send to Phrase** for the first time. LanguageCheck does not show the saved token afterward. To change it, open **Settings** > **Phrase**, select **Replace access token**, and submit the new token.

## Steps

1. Open a completed MXLIFF check.
2. Select **Send to Phrase**.
3. If prompted, enter your Phrase TMS access token and select **Submit**.
4. Follow the remaining modal instructions.
5. Wait while LanguageCheck processes and sends the evaluation to Phrase.

## Notes and Limitations

The Phrase connection is associated with your LanguageCheck account. If sending results fails, check that the Phrase connection is active and replace the access token in Settings if needed.
