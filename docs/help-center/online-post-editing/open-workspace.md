# Open the Online Post-editing Workspace

<div class="plan-badges"><span class="plan-badge plan-pro">Pro</span><span class="plan-badge plan-team">Team</span></div>

Open online post-editing to review, filter, and edit segments directly in LanguageCheck.

## Steps

1. Open a completed check.
2. In **Post-editing**, select **Start post-editing**.
3. Use filters to focus on specific segments.
4. Edit target text if you have Pro access or collaborator access to this check.

## Segment Alerts

The post-editing workspace can show alerts beside a segment's target length when the corresponding option was enabled before the check was run:

- **Target length:** the target exceeds the configured length rule.
- **Short segment:** the source contains the configured number of words or fewer.

Hover over an alert to see its configured limit.

## Notes and Limitations

Standard users can view and filter results online, but editing and export are Pro or Team features.
